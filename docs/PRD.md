# AvatarLink / Avatar Companion Studio PRD

## Goal
Ship a browser-native MVP that lets a user upload a VRM avatar, preview it, configure a safe companion persona, and chat through a no-code operator UI.

## Positioning
AvatarLink is a **no-code VRM/VTuber AI avatar companion engine** for creators, studios, community teams, and character IP owners.

## Explicit non-goal
Do not market or optimize this MVP as an unrestricted NSFW AI girlfriend product.

## v1 features
1. Safety + asset-rights onboarding
2. VRM file upload and preview shell
3. Persona editor
4. Chat panel and system prompt preview
5. OpenAI-compatible BYOK settings
6. TTS adapter stub and lip-sync signal stub
7. Exportable session JSON later

## Risks
- Browser VRM rendering performance across machines
- BYOK UX without secrets leakage
- Content safety controls before persistent chat is added
